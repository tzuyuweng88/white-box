# Manual verification

Run npm run build before checking the affected experience in a browser.

1. Explore Honesty and Independence, enter definitions and guidelines, and save both.
2. Check the board and its Move Up / Move Down controls.
3. Start The Group Project, choose an action, select relevant values, and explore competing considerations.
4. Read consequences, explore another response, and make a final decision.
5. Rank values and inspect the before/after comparison. Confirm board order changes only when explicitly applied.
6. Revise Respect during reflection and check the updated wording on the board and guide.
7. Complete the essay and photo dilemmas.
8. Review all histories, retry a dilemma, and check that prior attempts remain.
9. Change guide format, theme, background, font, icons, sticker, arrangement, and order. Save and reload.
10. Download PNG and PDF files. Inspect every selected value, definition, and guideline for clipping. Confirm private reflections stay outside exports.
11. Edit a value later and verify it after reload.
12. Check profile navigation, accessibility settings, reflection deletion, Reset Demo, keyboard access, and a narrow screen around 390px wide.
